# 商品管理  
## 主な機能  
入力エリアに商品名,単価,数量を入れると追加した商品の表、統計量が見れる  
同じ商品名かつ同じ単価のものが登録された場合はもともと登録している数量に加算される  
## 修正点、変更点  
index.htmlの基本的な枠組みの作成
main.tsに基本的なロジックの追加  
買い物リストにバリデーションの空文字、数字以外の場合のバリデーションの追加を行った  

## 学んだこと
.gitignoreにnode_modules/を入れ忘れていてaddしてしまったが、毎回のaddした後にgit statusで確認する癖のおかげで気づけた  
addしたものを消すには git reset ファイル名　みたいな感じでする  
form内のbuttonはtype="button"とすることでリロードされずにUXを向上させれる  
interfaceを使うことでtsらしい安全なコードで書ける
